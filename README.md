# Фонд помощи животным «Ника»

Репозиторий проекта фонда помощи животным «Ника».

## Как присоединиться

1. Установите [Git](https://git-scm.com/downloads).
2. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/KONTROLIK/nika-animal-fund.git
   ```

3. Создайте ветку под свою задачу, внесите правки и запушьте её.
4. Откройте pull request — правки обсудим и вольём.

Нужен прямой доступ на запись? Попросите владельца добавить вас в
**Settings → Collaborators** репозитория.

## Структура

Проект только начинается — структура появится вместе с первым кодом.
