# PET CONNECT — умный подбор питомца

Сервис умного подбора питомца для фонда помощи животным «Ника».

## Запуск

Нужны Docker Desktop и Docker Compose.

```bash
copy .env.example .env
# замените значения паролей и JWT_SECRET в .env
docker compose up --build
```

Откройте `http://localhost:8080`. Контейнеры поднимут React/Vite frontend, FastAPI backend и PostgreSQL. Миграции и загрузка каталога выполняются при старте backend.

## Возможности

- обзор с визуальной системой PET CONNECT и карточками питомцев;
- каталог с фильтрами и избранным;
- регистрацию с автоматическим переходом в чат;
- диалог с персональным помощником и постепенное заполнение анкеты;
- сохранение анкеты в `localStorage` и историю контекста;
- менеджерскую панель;
- центр подбора с понятным объяснением формирования рекомендаций;
- выбор сердцем (Pet Tinder) с серверным сохранением свайпов;
- закрытая панель менеджера с ролью `MANAGER` и событиями WebSocket.

Карточки животных взяты с публичной страницы фонда «НИКА» и содержат источник. Пользовательские записи и внутренняя аналитика доступны только авторизованным сотрудникам.

Обновить локальный срез карточек можно командой `uv run --with httpx --with beautifulsoup4 --with pandas --with json5 scripts/parse_animals.py`. Скрипт извлекает полный публичный каталог фонда и завершается с ошибкой при изменении формата источника, чтобы новые данные не подменялись выдуманными.

## Подключение Nemotron

Ключ API **не нужен для запуска локального fallback и не хранится в браузере**. Для подключения AnyModel задайте переменные в локальном `.env`:

```env
AI_BASE_URL=https://anymodel.org/v1
AI_MODEL=am/nemotron-3-ultra-550b-a55b
AI_API_KEY=...
```

Файл `.env` игнорируется Git. Никогда не вставляйте ключ в frontend или Dockerfile. Backend использует его только для server-side запроса к AnyModel.

## Визуальная основа

Композиция вдохновлена указанным референсом: светлая редакционная сетка, большие фотографии, зелёный природный цвет, лаймовый акцент и эмоциональные карточки. Логотип, тексты и графические материалы PET CONNECT самостоятельные.

## Как присоединиться

1. Установите [Git](https://git-scm.com/downloads).
2. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/KONTROLIK/nika-animal-fund.git
   ```

3. Создайте ветку под свою задачу, внесите правки и запушьте её.
4. Откройте pull request — правки обсудим и вольём.

Нужен прямой доступ на запись? Попросите владельца добавить вас в
**Settings → Collaborators** репозитория.

## Структура

- `backend/` — FastAPI, SQLAlchemy, Alembic, JWT, AI и WebSocket;
- `frontend/` — React + TypeScript + Vite;
- `data/animals.json` — последний проверенный срез публичного каталога;
- `docker-compose.yml` — PostgreSQL, API и web.
